# 🎫 티켓런 (TicketRun)

실제 티켓 예매 과정(카운트다운 → 대기열 → 관람일 선택 → 보안문자 → 좌석 선택)을 반복 연습하고, 구간별 기록 분석으로 부족한 구간을 찾아 집중 연습할 수 있는 티켓팅 연습 서비스입니다.

> 실전 연습 → 결과 분석 → 취약 구간 집중 연습 → 실전 재도전

## 주요 기능

### 실전 연습

- [ ] 공연 상세 / 예매 카운트다운 (정각 대비 클릭 오차 측정)
- [ ] 대기열 (순번 감소, 반복 클릭 패널티)
- [ ] 관람일·회차 선택
- [ ] 보안문자 입력
- [ ] 좌석 선택 (좌석 소진 시뮬레이션, 선점 실패, 취소표 등장)

### 개별 연습

- [ ] 카운트다운 클릭 연습
- [ ] 보안문자 연습
- [ ] 지정 좌석 선택 연습
- [ ] 취소표 잡기 연습

### 결과 및 기록

- [ ] 구간별 소요 시간 및 실수 기록
- [ ] 취약 구간 분석 및 집중 연습 추천
- [ ] 연습 기록 저장 (IndexedDB)
- [ ] 속도 추이 그래프

## 기술 스택

| 분류        | 기술               |
| ----------- | ------------------ |
| Framework   | React + TypeScript |
| Build       | Vite               |
| Routing     | React Router       |
| State       | Zustand            |
| Style       | Tailwind CSS       |
| Lint/Format | ESLint, Prettier   |

## 실행 방법

```bash
npm install
npm run dev
```

## 폴더 구조

```
src/
├── app/            # 앱 설정 (레이아웃, 라우터)
├── pages/          # 라우트별 페이지
├── features/       # 기능별 묶음 (컴포넌트, 훅, 스토어)
│   ├── booking/    # 예매 흐름 (단계 전환)
│   ├── concert/    # 공연 정보
│   ├── countdown/  # 예매 카운트다운
│   ├── queue/      # 대기열
│   ├── schedule/   # 관람일·회차 선택
│   ├── captcha/    # 보안문자
│   ├── seat/       # 좌석맵, 좌석 소진·취소표
│   ├── drill/      # 개별 연습
│   └── record/     # 측정, 기록 저장, 분석
├── common/         # 공용 컴포넌트, 훅, 유틸
├── types/          # 공통 타입
└── data/           # 공연·좌석 데이터
```
